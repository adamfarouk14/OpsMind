# Templates

Ready-to-copy structures for the knowledge the support team keeps in OpsMind.

| Template | Use it for |
|---|---|
| [Device Knowledge Case](Device-Knowledge-Case-Template.md) | A device fault that was diagnosed and fixed, a workaround still open, or a recurring incident worth handing to the next technician. |

## How to use a template

1. Copy the file's section headings into a new document.
2. Fill every section; write "Not applicable" instead of deleting one, so the next reader knows it was considered.
3. Attach photos, logs, or vendor sheets as files rather than pasting them into the text.
4. Keep one case per document. Two faults in one page cannot be found again by search.

Documents written from these templates still go through the normal review before they are published to the team.
